# 🇮🇳 Sarkari Yojna Setu

### Your Bridge to Government Schemes

Sarkari Yojna Setu is a responsive web platform designed to help users discover and explore government schemes in India through a simple and accessible interface.

The platform organizes schemes by categories such as health, education, agriculture, housing, finance, skill development, women welfare, and social welfare.

---

## ✨ Features

- 🔍 Search government schemes
- 🎯 Filter schemes by:
  - Sector
  - Gender
  - Age group
  - Income group
- 🌐 Hindi / English language support
- ⭐ Save schemes for later
- 🔥 Top schemes section
- 📋 Detailed scheme information
- 🚀 Direct "Apply Now" links
- 🖼️ Scheme images
- 🎥 Scheme-related videos
- 📱 Responsive design for different screen sizes
- 💾 Browser-based saved schemes using localStorage
- 📊 JSON-based scheme data management
